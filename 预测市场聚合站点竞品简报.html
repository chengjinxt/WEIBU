04 / WHITE SPACE

中文站的六个空白

空白不等于都值得做。优先级应由“中文用户立刻能理解”和“无需接触交易资金”决定，而不是技术炫技。

01

中文异动榜 + 事件解读

把概率走势、大额交易和新闻节点翻译成中文解释，是最直接的内容差。英文站提供数据，中文用户缺的是“为什么变”。

02

概率 × 民调 × 新闻时间线

同一事件并排展示市场概率、民调均值与新闻时间线。现有产品多停留在异动展示，缺少归因层。

03

A 股 / 港股与宏观政策解读

围绕影响中文投资者的宏观政策、地缘与市场事件做概率解读；英文站更聚焦美国政治与美股。

04

跨品类情绪指数

将政治、宏观、科技、加密等品类的资金流与概率变化合成为情绪指标。目前未发现专职产品。

05

中文预警推送

将大户异动与关键概率突破转换为中文提醒。现有英文预警多为付费，中文 Telegram 生态仍很小。

06

跨平台价差解释器

不是只报“相差几个点”，而是解释费用、结算规则和流动性差异。Predictions.io 已有英文工具，未见中文版。

05 / ENTRY PLAN

建议切口：先做媒体型数据页

核心产品不是“大而全终端”，而是每天值得点开的中文事件页。先验证中文解释与引用需求，再决定是否扩展 API 或预警。

最小可行栏目

把海外成熟功能里最安全、最能形成内容壁垒的部分组合起来。

  1. 今日异动
    按 24 小时 / 7 日概率变化，列出变化与时间点。
  2. 事件解释页
    概率曲线 + 规则摘要 + 新闻时间线 + 中文归因。
  3. 跨平台对照
    仅展示同题概率与结算口径差异，不提供下注入口。
  4. 可引用快照
    借鉴 DeFi Rate，为记者和研究者保留带时间戳的页面快照。

先不做：跟单与钱包复制

海外已有多个成熟工具，而且触及投顾、内幕交易审查与大陆赌博共犯风险，不适合作为中文产品起点。

先不做：重型订单簿 API

Bitquery、Resolved Markets 已服务专业量化团队。中文站早期更缺解释层，而非更深的底层数据管道。

验证对象

优先面向记者 / 研究者与只读行情用户；活跃交易员的预警需求可后置验证，并与交易导流严格隔离。

06 / BUSINESS

海外怎么赚钱

已验证的收入路径有订阅、API 和返佣。但对中文站而言，商业模式不能只看收入效率，还要看合规暴露。

订阅 / 预警

Polyanna 把鲸鱼雷达、Telegram / 邮件 / webhook 预警和 API 放进付费层。

可借鉴：内容订阅，不连接交易。

专业数据 API

Resolved Markets：Pro 17 美元/月、Scale 49 美元/月、Enterprise 549 美元/月；Apify 抓取服务为每千条 1 美元。

可后置：有稳定数据资产后再做。

开户返佣 / 跟单

DeFi Rate 使用 Kalshi / Polymarket 注册返佣；YouTube 中文博主也挂推荐链接。

不建议：在大陆语境下风险最高。
07 / COMPLIANCE

合规边界决定产品形态

以下为研究整理，不是法律意见。纯信息展示的风险相对低，不代表无风险；真正危险的是导流、返佣、发展会员与跟单执行。

中国大陆

  • 事实：刑法第 303 条规制赌博罪、开设赌场罪与组织参与国（境）外赌博罪。
  • 事实：2010 年两高一部意见明确，明知是赌博网站仍投放广告、发展会员、提供软件开发或技术支持并收费，可按开设赌场罪共犯论处。
  • 判断：预测市场大概率会被认定为赌博；仅做无下注入口、无返佣的信息展示，刑事风险相对较低，但仍属灰色地带。
建议红线：不做交易入口、不挂返佣、不收推广费、不做自动跟单；正式上线前咨询律师。

美国

  • 事实：CFTC 将事件合约定性为衍生品 / 掉期而非赌博，并在 2026 年推进事件合约内幕交易执法。
  • 事实：44 个州总检察长主张州赌博法适用，联邦与州的管辖争议仍在持续。
  • 判断：纯数据与比价服务风险相对低；返佣导流可能被视为协助未注册业务，跟单信号还可能触发投顾风险。
风险点：各州赌博法差异、平台开户导流、付费信号，以及复制疑似内幕交易者。
